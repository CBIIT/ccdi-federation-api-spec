# Childhood Cancer Data Initiative (CCDI) Data Federation Resource

## 1.3.0 Release Notes
_Jagu, Subhashini (NIH/NCI)_

### **Release Notes: Data Federation Resource API V1.3.0**

The Childhood Cancer Data Initiative (CCDI) releases version 1.3.0 of
the [Data Federation Resource API](https://cbiit.github.io/ccdi-federation-api-aggregation/).

**API Updates**

- **Diagnosis Categories Data**: the `/sample, /subject, /sample-diagnosis and /subject-diagnosis` endpoints entities now can provide `diagnosis_category` data.

- **Diagnosis Categories Search**: the `/sample, /sample-diagnosis and /subject-diagnosis` endpoints now
  supports a `diagnosis_category` search parameter.

- **Study ID**: the `/namespace` endpoint 'study_id' uses CDE 6380045 v1.00 and it is just a text value instead of using a fixed list values.

- **Institution**: the `/organization` endpoint 'institution' uses CDE 1100 v4.00 and it is just a text value instead of using a fixed list values.
